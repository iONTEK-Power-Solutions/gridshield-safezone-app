✓ Installed — find Safe Zone PH on your home screen
iPhone / iPad — 3 taps, tapos may icon ka na:
  1. Tap ⋯ (three dots) sa kanang-ibaba ng Safari. Kung Share □↑ ang nakikita mo sa gitna, tap 'yun.
  2. Hanapin at tap Add to Home Screen (scroll pababa kung hindi agad kita)
  3. Tap Add sa kanang-itaas. Tapos! Hanapin ang Safe Zone PH icon sa home screen.
Bakit hindi one-tap sa iPhone? ▾
Apple does not allow any web app to install itself in one tap — every iPhone web app (banks, government, news) uses these same 3 taps. The one-tap version of Safe Zone PH is coming to the App Store. Sa Android, one-tap na ngayon.
Must be opened in Safari — not the Facebook / Messenger / Viber in-app browser. Kung galing ka sa FB: tap ⋯ → Open in Safari muna.
Android — kung walang lumabas na Install prompt:
  1. Tap ⋮ (three dots) sa kanang-itaas ng Chrome
  2. Tap Add to Home screen o Install app
  3. Tap Install. Tapos! Hanapin ang Safe Zone PH sa home screen.
Must be opened in Chrome — not the Facebook / Messenger in-app browser. Kung galing ka sa FB: tap ⋮ → Open in Chrome muna.
